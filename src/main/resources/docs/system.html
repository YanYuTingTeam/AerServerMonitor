系统相关

GET /system/status

获取系统信息. 包括操作系统, CPU, 内存, JVM 等信息.

响应

{
    "code": 200,
    "errcode": 0,
    "message": "success",
    "data": {
        "os_name": "Linux",
        "os_version": "6.12.21",
        "os_arch": "amd64",
        "available_processors": 8,
        "total_physical_memory": 17179869184,
        "free_physical_memory": 8589934592,
        "cpu_load": 0.35,
        "total_memory": 536870912,
        "free_memory": 268435456,
        "max_memory": 1073741824,
        "used_memory": 268435456,
        "jvm_uptime": 3600000,
        "jvm_version": "17.0.2",
        "jvm_name": "OpenJDK 64-Bit Server VM"
    }
}

cpu_load 和 physical_memory 字段仅在使用 HotSpot JVM 时可用.
