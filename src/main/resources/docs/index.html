鉴权概览

系统采用三条独立鉴权路径, 详见 鉴权文档:

  • 外部 API — HMAC-MD5 (salt + body/origin) — a + b 头
  • Dashboard — JWT + HMAC-SHA256 (jwt + body) 双重校验 + CSRF Origin 防护
  • WebSocket — 握手时 JWT + HMAC-SHA256 (jwt + "ws-handshake:" + a) 校验
