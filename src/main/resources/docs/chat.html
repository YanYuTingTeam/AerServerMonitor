聊天相关

POST /chat/command

使用命令. 整个 body 为命令内容.

请求示例

POST /chat/command
Body: /glist

成功响应

{
    "code": 200,
    "errcode": 0,
    "message": "CONSOLE executed command: /glist\n[pit] (1): ApartPenguin141\n[lobby] (1): YukiEnd\nTotal players online: 2",
    "data": {}
}

message 为命令执行后的返回内容. 可能为空.

命令不存在

{
    "code": 404,
    "errcode": 30001,
    "message": "Command not found",
    "data": {}
}

命令执行出错

{
    "code": 500,
    "errcode": 30002,
    "message": "line1\nline2\nAn Internal error occurred while exec...",
    "data": {}
}

如果命令执行到一半才报错, message 会包含已经输出的内容和报错信息.

GET /chat/history

获取聊天记录. 参数可不带, 可只带一个, 可全带.

参数类型必填说明
timefromlong(ms)否从这个时间开始的消息
timetolong(ms)否到这个时间截止的消息

响应

{
    "code": 200,
    "errcode": 0,
    "message": "success",
    "data": {
        "messages": [
            {
                "msgid": "20260714024600ABCD1234A1E5F8G2",
                "count": 156,
                "daycount": 23,
                "time": 1720886400000,
                "name": "Steve",
                "uuid": "xxx-xxx-xxx",
                "server": {
                    "name": "lobby",
                    "ip": "127.0.0.1:25577",
                    "describe": "A Lobby"
                },
                "content": "hello everyone"
            }
        ]
    }
}

count 为该玩家总发言数, daycount 为该玩家当日发言数.

参数错误

{
    "code": 400,
    "errcode": 0,
    "message": "参数错误",
    "data": {}
}
