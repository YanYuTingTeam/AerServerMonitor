日志相关

GET /log/get

查询日志条目. 支持按类型, 时间范围筛选, 支持分页.

参数类型必填说明
tint否返回条数 (默认 50, 最大 500)
offsetint否偏移量. 从范围里最新的一条向上偏移多少条
typestring否级别过滤: REQUEST/RESPONSE/CHAT/GAME/OPERATION/OTHER (逗号分隔多选)
timefromlong(ms)否起始时间戳
timetolong(ms)否结束时间戳

响应

{
    "code": 200,
    "errcode": 0,
    "message": "success",
    "data": {
        "total": 1500,
        "offset": 0,
        "count": 50,
        "logs": [
            {"raw": "[CHAT][msgid][eventid][2026-07-14 02:46:00.123] lobby | Steve (uuid) | hello"},
            {"raw": "[REQUEST][logid][2026-07-14 02:46:01.456] GET . /player/info (200) | 1720886400000 | abc123"}
        ]
    }
}

GET /log/getlog

根据 logid 查询完整请求链. 返回该 logid 关联的 REQUEST + RESPONSE + OPERATION 完整记录.

参数类型必填说明
idstring是日志 ID

响应

{
    "code": 200,
    "errcode": 0,
    "message": "success",
    "data": {
        "logid": "20260714024600ABCD1234A1E5F8G2",
        "entries": [
            {"raw": "[REQUEST][logid][...] GET . /player/info (200) | a头 | b头"},
            {"raw": "[OPERATION][logid][...] logid: 查询 Redis: miss, 查询 MySQL: hit"},
            {"raw": "[RESPONSE][logid][...] logid: {\"code\":200, ...}"}
        ]
    }
}

GET /log/getmsg

根据 msgid 查询消息详情.

参数类型必填说明
idstring是消息 ID

响应

{
    "code": 200,
    "errcode": 0,
    "message": "success",
    "data": {
        "msgid": "20260714024600ABCD1234A1E5F8G2",
        "time": 1720886400000,
        "name": "Steve",
        "uuid": "xxx-xxx-xxx",
        "ip": "192.168.1.50",
        "servername": "lobby",
        "content": "hello everyone"
    }
}

GET /log/getevent

根据 eventid 查询事件详情.

参数类型必填说明
idstring是事件 ID

响应

{
    "code": 200,
    "errcode": 0,
    "message": "success",
    "data": {
        "eventid": "20260714024600ABCD1234A1E5F8G2",
        "entries": [
            {"raw": "[GAME][eventid][2026-07-14 02:46:00.123] lobby | Steve (uuid) | lobby -> pit"}
        ]
    }
}

未找到

如果 logid/msgid/eventid 未找到, 返回 errcode 70003.
