玩家相关

GET /player/info

获取玩家信息. 支持批量查询, 参数用逗号分隔, 按顺序一一校验.

参数类型必填说明
uuidstring否玩家 UUID (逗号分隔支持批量)
namestring否玩家名 (逗号分隔支持批量)

如果两个参数都带了, 则校验 uuid 和 name 是否为同一个人. 如果不是则返回对应业务码.

正常响应

{
    "code": 200,
    "errcode": 0,
    "message": "success",
    "data": {
        "name": "Steve",
        "uuid": "xxx-xxx-xxx",
        "ip": "192.168.1.50",
        "online": true,
        "server": {
            "name": "lobby",
            "ip": "127.0.0.1:25577",
            "describe": "A Lobby"
        },
        "skin": "xxx-xxx-xxx",
        "firstjoin": 1720000000000,
        "lastjoin": 1720886400000,
        "leave": 0
    }
}

玩家不在线

errcode 为 10006, 但如果有记录仍会正常返回 data (返回的是最后一次记录的数据).

批量查询

参数用逗号分隔, 如 ?uuid=uuid1,uuid2,uuid3. 返回 data.players 数组, 每个元素独立携带对应的 code 和 errcode.

{
    "code": 200,
    "errcode": 0,
    "data": {
        "players": [
            {"code": 200, "errcode": 0, "player": {...}},
            {"code": 400, "errcode": 10006, "player": {...}},
            {"code": 400, "errcode": 10001, "player": null}
        ]
    }
}

GET /player/list

获取在线玩家列表, 支持分页.

参数类型必填说明
tint否返回条数, 不传则返回全部
offsetint否偏移量, 默认 0

正常响应

{
    "code": 200,
    "errcode": 0,
    "message": "success",
    "data": {
        "total": 5,
        "players": [
            {
                "name": "Steve",
                "uuid": "xxx-xxx-xxx",
                "server": {
                    "name": "lobby",
                    "ip": "127.0.0.1:25577",
                    "describe": "A Lobby"
                },
                "skin": "xxx-xxx-xxx"
            }
        ]
    }
}

total 为当前在线总人数, 不受分页参数影响. players 数组格式与 /server/list 中的 players 一致.

POST /player/kick

从代理端踢出玩家. 整个 body 作为踢出理由.

参数类型必填说明
uuidstring否玩家 UUID
namestring否玩家名

成功响应

{
    "code": 200,
    "errcode": 0,
    "message": "success",
    "data": {
        "name": "Steve",
        "uuid": "xxx-xxx-xxx",
        "ip": "192.168.1.50",
        "server": {
            "name": "lobby",
            "ip": "127.0.0.1:25577",
            "describe": "A Lobby"
        },
        "skin": "xxx-xxx-xxx"
    }
}

玩家不在线/不存在

code 为 400, errcode 为 10003/10004/10005/10006. data 中只返回有记录的字段, server 为 {}.
