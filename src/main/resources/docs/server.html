子服相关

GET /server/list

获取子服列表. 如果 ping 为 true, 则通过 SLP ping 每个子服获取实时信息; 否则返回记录中的数据.

参数类型必填说明
pingboolean否是否 SLP ping 子服. 默认 false

    "message": "success",
    "data": {
        "servers": [

                "name": "lobby",

                "port": 25577,

online 为记录的数据中正在该子服的玩家数, 不包含 motd/ico/version/max 字段.

GET /server/info

获取子服信息. name 和 port 二选一, 前两个参数和 ip 二选一. 支持批量查询 (逗号分隔).

参数类型必填说明
namestring否子服名
portint否子服端口
ipstring否直接 SLP ping 该 IP (受 SSRF 防护限制)
pingboolean否是否 SLP ping. 默认 false

参数校验

name 和 port 同时存在会校验是否为同一个子服. 传入过多参数 (name port ip 同时存在) 返回 400.

如果传入了 ip, 则直接 SLP ping 这个 ip, 忽视 ping= 参数.

特殊业务码

errcode含义
20001服务器离线 (ping 不到)
20002通过 name 找不到子服
20003通过 port 找不到子服
20004name 和 port 不匹配 (name 匹配到的)
20005name 和 port 不匹配 (port 匹配到的)
20006port 匹配到的子服过多
20007name 匹配到的子服过多 (不影响正常返回)
20008子服不存在
