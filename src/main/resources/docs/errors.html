errcode含义可能原因

10002通过 name 找不到玩家无该玩家的记录

WebSocket 相关 (60xxx)

errcode含义可能原因
60001连接数达到上限WebSocket 连接数超过 ws.max-connections (默认 500)
60002鉴权失败握手时 token / a / b 任一缺失或校验失败, 详细 message 见 鉴权文档

CSRF 校验失败

当 POST/DELETE/PUT 请求的 Origin/Referer 既非同源也不在白名单时, 服务端返回:

{"code":403, "errcode":50001, "message":"origin not allowed"}

这是与 50001 鉴权失败不同的场景, 但共用 errcode 便于前端统一处理.
